# 隐私政策与数据安全准则

最后更新：2026年10月25日 ｜ 制定机构：网络诊断实验室合规委员会 ｜ 规范代号：NZD-POL-PRIVACY-2026

## 一、引言与隐私保护基本原则

网络诊断实验室（NetZhenDuan.cc，以下简称“本站”或“实验室”）深知个人隐私与网络数据安全对广大工程师、技术研究人员及普通使用者的极端重要性。我们在开发在线网络探针控制台、编写网络诊断文档及开展网络质量测评的全部业务生命周期中，始终恪守“隐私优先”（Privacy-by-Design）与“最小必要采集”（Data Minimization）的技术伦理。

本《隐私政策》详细阐明了当您访问本站、查阅排障文档、使用在线连通性探针或通过外链跳转至第三方技术资源时，我们对网络数据与访问信息的处理准则、技术实现边界及安全防护措施。

```
+-----------------------------------------------------------------------------------------+
|                               网络诊断实验室 端侧本地计算隐私安全模型                           |
+-----------------------------------------------------------------------------------------+
|  [用户端设备]   浏览器本地 JavaScript / WebAssembly 实时执行网络探针与订阅解析            |
|                                         |                                               |
|                    ======== [本地隐私零回传安全屏障] ========                           |
|                                         |                                               |
|  [远端服务器]   仅提供静态 HTML/CSS/JS 资源托管与 CDN 边缘缓存，绝不收集用户敏感配置数据  |
+-----------------------------------------------------------------------------------------+
```

我们庄严承诺：**网络诊断实验室绝不在服务器端沉淀任何可关联至特定用户的身份数据，绝不转存、转卖或窥探用户的代理订阅链接、节点凭证、私钥参数或真实网络流量。**

## 二、我们收集或不收集哪些信息？

### 2.1 浏览器端探针工具：100% 本地运算，零敏感数据回传

本站提供了多种用于网络故障自查的前端网络探针工具（如 WebRTC 真实公网 IP 泄漏检测、本地 DNS 劫持验证、订阅节点 YAML 语法静态解析与端口连通性探测）。

在技术实现上，这些工具全部基于浏览器端原生技术（HTML5、JavaScript、WebRTC API 及 WebAssembly）运行：
1. **订阅链接与配置文件解析**：当您在相关诊断页面粘贴或输入配置文件内容时，代码完全在您本地浏览器的 JavaScript 虚拟机内存中执行静态语法拆解与报错分析。**该过程绝对不会通过 HTTP POST 或 WebSocket 向本站后端或任何第三方服务器上传任何配置文本、URL 链接或节点密钥**。
2. **本地网络接口与延迟探针**：探针发起的 STUN 探测请求或目标域名连通性测试，由您的浏览器客户端直接与目标公网测试节点建立短暂的网络连接。测量得到的往返时延（RTT）、丢包率及 IP 属性仅动态渲染在您的前端界面上，一旦关闭或刷新网页，相关内存数据立即彻底销毁。

### 2.2 基础 Web 访问数据与服务器日志

当您访问本站任何静态文档页面时，我们的托管基础设施（包括 Cloudflare 边缘节点及云服务商 CDN）会自动记录标准的 HTTP 请求元数据：
- **访问时间戳**与请求的统一资源定位符（URL）；
- 客户端浏览器类型及操作系统版本（`User-Agent` 标头）；
- 客户端大致来源 IP 地址（用于防御恶意 DDoS 洪水攻击、阻断自动化扫描器及执行地理区域负载均衡）；
- 页面加载状态码与传输字节数。

**日志保留与脱敏策略**：上述基础设施边缘网络日志主要用于排查 502/504 等服务器连接故障及网络安全攻击取证，由 CDN 服务商自动加密轮转，并在保留 14 天至 30 天后由系统自动覆写销毁。本站绝不将上述访问日志与任何特定的个人真实身份、电话号码或家庭住址进行画像绑定。

### 2.3 关于 Cookie 与本地跟踪技术

1. **零第三方跨站追踪**：本站坚决不植入任何跨站行为追踪 Cookie、Facebook Pixel、Google AdSense 商业再营销像素或任何第三方用户画像追踪代码。
2. **纯功能性本地存储（Functional Storage Only）**：本站仅在用户浏览器本地的 `localStorage` 中存储极其有限的界面偏好配置：
   - 界面暗黑模式与明亮模式的主题切换标记（`vitepress-theme-appearance`）；
   - 用户收起或展开左侧故障排查目录的折叠状态。
   这些存储纯粹为了优化读者的本地阅读体验，不包含任何个人身份信息，用户可随时通过浏览器设置一键清除。

## 四、技术安全防护措施与传输加密

网络诊断实验室采取了业界最高规格的技术与工程手段，全力确保本站访问全链路的数据机密性与完整性：

1. **全站强制启用现代 TLS 传输加密**：
   - 本站全网强制启用 HTTPS 协议访问，全面支持并优先协商 **TLS 1.3** 协议，支持向前保密（Forward Secrecy）强密码套件（如 `TLS_AES_128_GCM_SHA256`、`TLS_CHACHA20_POLY1305_SHA256`）。
   - 彻底废除不安全的 SSLv3、TLS 1.0 与 TLS 1.1 协议，防止任何潜在的 POODLE 或 BEAST 中间人降级截获攻击。
2. **全维度严格安全响应头（HTTP Security Headers）**：
   - **HSTS（HTTP Strict Transport Security）**：全站部署 `Strict-Transport-Security: max-age=31536000; includeSubDomains; preload`，强制所有主流浏览器拒绝一切明文 HTTP 降级请求。
   - **Content Security Policy（CSP 内容安全策略）**：严格限制网页内部脚本执行来源，严禁加载未授权的外部恶意 JavaScript，全面免疫跨站脚本（XSS）攻击。
   - **X-Content-Type-Options: nosniff**：阻止浏览器对响应内容执行 MIME 类型嗅探，杜绝恶意脚本伪装为图片或文本执行。
   - **Referrer-Policy: strict-origin-when-cross-origin**：在用户跳转至外部链接时，仅向目标服务器传递本站的顶级域名来源，绝不向外部暴露具体的文章路径或查询参数。

## 五、未成年人隐私特别保护

网络诊断实验室的技术内容面向具备计算机网络基础知识的专业工程师、高校师生及成年网络使用者。本站绝不在知情的情况下收集、存储或索取任何 14 周岁以下未成年人的个人数据。如果法定监护人发现未成年人在未经许可的情况下向本站提交了任何反馈信息，请立即与我们联系，我们将在核实后第一时间进行不可逆的永久销毁。

## 六、用户的隐私权益与数据请求权

依据包括中华人民共和国《个人信息保护法》（PIPL）、欧盟《通用数据保护条例》（GDPR）以及全球通行的隐私合规标准，您对自己的个人信息享有完整的知情权、访问权、更正权及撤销同意权。

鉴于本站坚持“零知识、无账户体系、零敏感日志沉淀”的技术架构，我们通常不持有任何可直接反向追溯至特定用户的数据库记录。如果您对本站任何公开文章中引用的技术数据、案例说明存在隐私侵犯顾虑，或者希望咨询有关您网络交互的具体处理方式，您可以随时向我们的数据保护团队发出书面申请。
