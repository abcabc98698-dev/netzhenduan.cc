# 关于网络诊断实验室 (NetZhenDuan.cc)

最后更新：2026年10月25日 ｜ 技术审计委员会：网络诊断实验室核心工程组 ｜ 状态：正式发布

## 一、实验室创立宗旨与核心使命

网络诊断实验室（NetZhenDuan.cc）成立于复杂的现代跨国广域网网络环境下。随着全球网络基础设施演进、多云互联架构普及以及跨境应用对高吞吐、低抖动实时通信需求的指数级增长，普通用户与专业工程团队在访问跨境公网资源、部署跨国研发链路与排查分布式网络故障时，正面临前所未有的技术屏障。

传统的网络排障多依赖单维度的 `ping` 报文或基于第三方的非受控测速脚本，此类工具无法揭示传输层 TCP 握手重传、TLS 密码套件协商失败、ALPN 降级、BGP Anycast 路由黑洞以及运营商晚高峰 QoS 动态流量整形等深层次工程缺陷。由于缺乏体系化的协议级诊断工具与客观公正的底层基础设施评测标准，网络从业者与终端用户长期处于“连不上不知其因、速度慢不知何解”的信息不对称困境。

网络诊断实验室的唯一使命是：**运用严谨的计算机网络工程科学方法、RFC 国际标准与全栈可观测性技术，打破跨境网络传输中的黑盒壁垒，为全球中文工程师、跨国技术团队与数字游民提供完全透明、零商业粉饰、经得起数据复核的故障排查指南与基础设施客观评估报告。**

## 三、全球分布式探测网络与基础设施拓扑

为确保技术排障与评测数据的全面性与真实性，网络诊断实验室在亚太、北美、欧洲以及中国大陆构建了高密度的自动化探测网络。我们的测量节点绝不采用共享宿主机上的超售虚拟容器，而是全部采用独占千兆/万兆上行带宽的高性能硬件探测宿主机。

### 3.1 探测节点地理分布与运营商矩阵

1. **中国大陆边缘探针群（31 省市全覆盖）**：
   - **中国电信（China Telecom）**：覆盖 163 骨干网（AS4134）关键节点与 CN2 GIA/VIP（AS4809）优质接入点。
   - **中国联通（China Unicom）**：覆盖 169 骨干网（AS4837）节点与 A 网 / CU Premium（AS9929）高规格专线出口。
   - **中国移动（China Mobile）**：覆盖 CMIN2（AS58807）核心出口及各省市移动家庭宽带主流局域网探针。
   - **教育科研网（CERNET / CERNET2）**：覆盖跨国学术链路探测，审计 IPv4/IPv6 双栈网络表现。
2. **亚太核心汇聚探测节点**：
   - **香港（HKG）**：直连 Equinix HK1/HK2 机房与 Mega-i 交换中心，监测 PCCW、HKIX 路由交换与跨境延迟。
   - **日本东京（NRT/HND）**：直连 Equinix TY8 与 AT TOKYO，监测 IIJ、NTT、KDDI 等一级运营商直连品质。
   - **新加坡（SIN）**：直连 Equinix SG1 与 Global Switch，覆盖东南亚核心路由拓扑。
3. **北美与欧洲主干骨干探针**：
   - **美西洛杉矶 / 圣何塞（LAX/SJC）**：直连 CoreSite LA2 与 Equinix SV1，监测跨太平洋海缆（TPE、NCP、FASTER）物理传输状态。
   - **欧洲法兰克福 / 伦敦（FRA/LHR）**：直连 DE-CIX 与 LINX，监控跨欧陆传输与欧亚大陆光缆跳数。

## 四、自研工程测试工具链与实验技术栈

网络诊断实验室坚持“工欲善其事，必先利其器”的工程信条。我们不依赖封闭且可能携带统计偏差的商业黑盒软件，而是完全自主构建与整合开源网络可观测性工具链：

1. **底层报文捕获与事件跟踪**：
   - 基于 Linux 内核 `eBPF`（Extended Berkeley Packet Filter）开发了高性能 `tc` 与 `sockops` 探针程序，实时捕获套接字状态变更、TCP 拥塞窗口（CWND）收缩、丢包重传及零窗口通告事件。
   - 基于 `libpcap` / `tshark` 自动化管道捕获 TLS 握手特征报文，精确分析 Client Hello 中的 Extensions 列表、Cipher Suites 顺序与 ALPN 协商标记。
2. **多协议客户端仿真框架**：
   - 基于开源 `Mihomo`（Clash.Meta 内核）与 `Sing-box` 源码深度定制的自动化调试客户端，能够在模拟弱网、丢包、高抖动环境下连续压测各种节点协议（Shadowsocks、VMess、VLESS-Reality、Trojan、Hysteria 2、TUIC v5）。
   - 内置精准的内存泄漏检测与 Wintun 虚拟网卡死锁监视模块，持续评估主流 GUI 客户端（如 Clash Verge Rev、v2rayN、Surge）在长时间高负载运行下的系统资源消耗。
3. **在线网络探针控制台（NetZhenDuan Probe Engine）**：
   - 实验室在前端页面集成了基于 WebAssembly 与 WebRTC 技术栈的客户端实时网络探针。用户无需安装任何危险的可执行插件，即可在浏览器端安全地完成本地 DNS 劫持验证、WebRTC IP 泄漏排查、系统代理端口侦听检查及目标节点延迟测试。

## 五、实验室评测与运营中立性法则

公信力是技术实验室的立身之本。为了确保所有技术结论与评测报告的绝对客观与中立，网络诊断实验室制定并坚决践行以下四条铁律：

1. **数据优先与不可篡改铁律**：所有测试报告中引用的晚高峰延迟数据、丢包率分布直方图、最大吞吐带宽与流媒体解锁成功率，均直接提取自自动化测试数据库原始日志。严禁为了照顾任何品牌方的情感或商业诉求而人为修饰数据、调高评分或隐瞒断流事实。
2. **商业合作零干预原则**：本站可能展示部分优质合规网络服务商的商业推荐信息或返利链接（Affiliate Links），以维持高昂的全球服务器机房租赁与骨干网络带宽开销。但我们郑重承诺：商业关系绝不与技术评测结果挂钩。任何存在恶劣虚标带宽、频繁跑路风险、欺诈用户或被技术审计发现植入中间人抓包蜜罐的服务商，将直接列入黑名单并全网通报，无论其承诺提供多高额的佣金赞助。
3. **开源精神与知识共享**：实验室输出的所有故障排查步骤、系统配置模板、规则集过滤脚本与排障流程图，均遵循 CC BY-NC-SA 4.0 国际知识共享协议，鼓励技术同行自由学习、探讨与非商业性传播。
4. **价格保护承诺**：通过本站推荐渠道访问或采购网络基础设施的用户，所支付的实际费用绝不会高于服务商官方公示价格，且通常享有实验室与品牌方争取的技术社区专属折扣。

## 六、合规指引与网络安全责任边界

网络诊断实验室恪守中华人民共和国网络安全法规及全球互联网通用道德规范：

- 实验室的所有技术文章、架构分析与排障工具，旨在指导工程师、科研工作者及合法跨国企业排查网络传输中的网络层与应用层故障，优化系统网络性能，提升跨国科研、软件开发、跨境电商及学术交流中的网络传输效率。
- 实验室坚决反对、抵制并将技术手段限制于任何破坏计算机信息系统安全、非法侵入他人网络、传播违法信息、窃取用户隐私或从事电信网络诈骗的恶意网络行为。用户在参考本站技术内容时，必须严格遵守所在国家与地区的法律法规。
