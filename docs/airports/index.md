## 模块二：核心对象、网络架构与概念界定

在对比具体参数前，必须彻底厘清科学上网领域最容易被商家混淆的三大技术概念：

```
+---------------------------------------------------------------------------------------------------+
|                                  常见代理网络架构对比拓扑模型                                     |
+---------------------------------------------------------------------------------------------------+

[类型 A: 廉价公网中转]
用户终端 ===(公网加密)===> [国内云中转机房] -----(公共互联网国际出口, 经GFW审查/QoS限速)-----> [海外落地]
* 致命痛点: 晚高峰骨干网拥塞，丢包率高达 15%~40%，频繁断流转圈。

[类型 B: 纯正内网专线 (IEPL / IPLC)]
用户终端 ===(加密握手)===> [国内专线入口机房] ====== (跨国内网专线直连, 物理光纤不经公网GFW) ======> [海外落地]
* 核心优势: 晚高峰 0 丢包，端到端延迟恒定，单线程 4K 秒开，彻底免疫敏感时期封锁。
+---------------------------------------------------------------------------------------------------+
```

### 1. 物理专线 (IEPL / IPLC) vs 公网中转 (Relay / Tunnel)
- **IEPL (International Ethernet Private Line，国际以太网私有专线)**：跨国电信运营商在二层（数据链路层）提供的点对点内网连接。数据在境内机房直接进入跨境物理光纤，不经过公网国际出口，**天然不经过 GFW 的审查与 QoS 丢包**。
- **公网中转**：服务商租用普通的阿里云、腾讯云国内服务器，将数据包通过普通公网加密发送至海外 VPS。一旦晚高峰公网国际出口拥堵，运营商会对其施加严苛的 QoS 限速，导致视频频繁缓冲。

### 2. 原生住宅 IP (Residential IP) vs 机房广播 IP (Datacenter IP)
- **原生 IP**：IP 注册归属地与服务器机房物理所在地完全一致（例如香港本土原生宽带）。在访问 Netflix、Disney+、ChatGPT、Claude、TikTok 时，平台风控系统会识别为真实海外居民，**不会触发“检测到使用代理”拦截或验证码轰炸**；
- **机房广播 IP**：服务商通过 BGP 宣告将其他地区的便宜 IP 广播到当前机房使用，极易被 OpenAI 等平台判定为“高危机房爬虫”而直接拉黑。

## 模块三：网络性能评估指标与客观标准

本实验室对机场线路的测试，坚决剔除商业宣传泡沫，基于以下 4 项硬指标：

| 评估维度 | 优秀 (Tier 1) | 合格 (Tier 2) | 劣质 (避坑指标) | 该指标说明了什么？ |
|---|---|---|---|---|
| **晚高峰丢包率** | **0.0%** | < 2.0% | > 8.0% | **稳定性的绝对核心**。只要丢包率超过 3%，TCP 协议就会剧烈降速，造成视频卡死。 |
| **单线程下行带宽** | **> 100 Mbps** | > 30 Mbps | < 10 Mbps | **决定 4K 拖拽与大文件拉取速度**。Speedtest 多线程跑分不能反映单视频播放体验。 |
| **端到端延迟抖动 (Jitter)**| **< 3 ms** | < 12 ms | > 35 ms | **延迟的稳定性**。抖动过大会导致网页请求建立缓慢，甚至语音通话断断续续。 |
| **流媒体/AI 原生解锁** | **全区非自制剧 + Claude/GPT免验证** | 仅自制剧支持 | 频繁阻断拦截 | 决定日常办公与娱乐的平滑度，无需反复更换节点。 |

## 模块六：网络底层原理解析：为什么专线能够抵御封锁？

### 1. 跨境网络物理拓扑实相
普通公网连接与 IEPL 专线在物理层的根本差异：
- **普通公网线路**：您的数据包在离开中国电信/联通骨干网后，经过北京/上海/广州的国际通信出入口局。此处部署有巨型分布式深度数据包检测集群（DPI）。DPI 系统通过机器学习实时计算数据流的熵值（Entropy）、TLS 握手特征、包长分布。一旦判定为未知加密代理，即刻下发 TCP RST 伪造重置包或阻断 IP；
- **IEPL 内网专线**：机场服务商在境内（如深圳/上海）租用机房，境内机房通过租用的电信/联通二层内网电路（物理裸光纤或 SD-WAN 专网），在完全闭合的内网中将流量穿透至香港落地机房。**整个跨境传输过程不经过公网国际网关，完全脱离 GFW 的检测视线**。

### 2. 晚高峰带宽拥塞与 QoS（服务质量）限速
- 国际出口公网带宽是极其昂贵的公共资源。每当晚上 20 点至 23 点全民追剧时，运营商国际出口利用率达到 95% 以上；
- 此时运营商路由器会触发 **QoS 丢包调度算法**：优先保证国家重点企事业单位的专线与高优先级商业流量，个人宽带的加密 UDP/TCP 流量会被强制丢弃，丢包率瞬间飙升至 30% 以上；
- **纯 IEPL 专线由于购买了独立的独占带宽（CIR: Committed Information Rate）**，不受公共骨干网拥挤影响，因此能够做到全天候 0 丢包。

## 模块八：实操与验证：购买后如何在晚高峰检验线路质量？

不要轻信任何商家的单方面承诺，购买套餐后，请在**当天晚上 20:30～21:30** 执行以下 4 步标准化质量自检：

### 步骤 1：连续 ICMP 与 TCP Ping 丢包率测试
1. 在 Windows 终端运行命令对当前连接的代理端口进行持续探测；
2. 观察 100 个探测包中是否有丢包。**合格的 IEPL 专线丢包率必须等于 0%**。若丢包率大于 5%，说明存在线路超售。

### 步骤 2：Fast.com 单线程流媒体吞吐测试
1. 打开浏览器进入 [Fast.com](https://fast.com)；
2. 点击“显示更多信息 (Show more info)”，重点查看 **「Unloaded」与「Loaded」延迟** 以及单线程实际速度；
3. 若单线程速度稳定在 **35 Mbps 以上**，说明 4K 秒开无压力。

### 步骤 3：YouTube 4K 详细统计数据核验
1. 在 YouTube 搜索播放任意 4K 60FPS 视频；
2. 在视频画面上点击鼠标右键，选择 **「详细统计信息 (Stats for nerds)」**；
3. 查看 **`Connection Speed`**（连接速度）：
   - 优质专线应稳定在 **50,000 Kbps～120,000 Kbps**；
   - 查看 **`Buffer Health`**（缓冲健康度）：若缓冲秒数持续大于 20 秒，说明网络极其强韧。

## 模块十一：常见疑问解答 (FAQ)

### Q1：为什么有的机场宣称自己是专线，但晚高峰依然卡顿？
- **答**：专线本身物理质量极佳，但关键取决于服务商**购买的总专线带宽 vs 招收的用户规模（超售比）**。如果服务商仅购买了 1Gbps 的 IEPL 专线，却招收了 2 万名活跃用户，晚高峰专线带宽同样会被挤爆。这也是为什么我们推荐具备老牌运营实力、严格控制超售比的知名品牌。

### Q2：我应该买年付套餐还是月付套餐？
- **答**：**强烈建议初次使用任何机场时，一律优先选择月付（或最小起步周期）！** 亲自在本地网络环境下测试 1~2 周晚高峰表现。确认完全满足个人需求后，再考虑年付享受折扣优惠，避免因不可抗力导致损失。

### Q3：为什么同一家机场，朋友用着很快，我用着很慢？
- **答**：因为中国大陆三网运营商（中国电信、中国联通、中国移动）在不同省份的骨干网互联质量千差万别。电信走 CN2/163，联通走 9929/4837，移动走 CMI。优质机场会采用三网 BGP 优化入口，但本地宽带质量依然会带来一定差异。
